# Medical Diagnostic Center – ServiceNow

## Project Overview

The Medical Diagnostic Center is a ServiceNow-based application developed
to provide a centralized digital platform for diagnostic test selection,
appointment booking, payment status, appointment tracking, and laboratory
report management.

## Main Features

- Diagnostic Test Catalog
- Diagnostic Test Selection
- Patient Details
- Appointment Booking
- Payment Status
- Appointment Tracking
- Appointment Cancellation
- My Lab Reports
- Report Details
- Automatic Laboratory Report Generation
- Notifications
- Role-Based Access Control

## Application Workflow

Login → Browse Tests → Select Test → Enter Patient Details
→ Book Appointment → Payment → Confirmation
→ Complete Test → Generate Report → View Lab Report

## Technology

- ServiceNow
- Service Portal
- HTML
- CSS
- JavaScript
- AngularJS
- GlideRecord
- Business Rules
- ServiceNow Custom Tables
- ACLs and Roles
